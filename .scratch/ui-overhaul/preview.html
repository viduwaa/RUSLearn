06 · Bottom navigation + settings

Four destinations, settings behind one gear

Today every jump routes through the dashboard. A 4-slot Material bar — Home · Papers · GPA · Tracking — puts the high-frequency destinations on every top-level screen. The second ring (Favourites, Offline, Request, Sign out) moves behind a ⚙ gear icon in the Home app bar: one tap, a clean settings sheet. Papers/GPA/Tracking open as top-level (no back arrow, state kept); everything else stays a stacked page with up-nav. 48dp targets, 12/13px labels. Every phone in this preview wears the bar — tap around.

Anatomy

Active = teal pill behind the icon. The same control as view_bottom_nav.xml — this preview's buttons are wired: clicking moves the pill.

09 · Android mapping

From mockup to res/

Swatches → values/colors.xml + values-night/colors.xml (this page’s CSS vars are a 1:1 copy)
Type cards → res/font/ IBM Plex TTFs + TextAppearance.RUSLearn.* styles in themes.xml
App bar → layout/view_toolbar.xml include (MaterialToolbar) — ticket 02
Paper row → item_paper.xml v2 + PaperAdapter — ticket 03
Empty states → view_empty_state.xml include with optional Retry — tickets 03/04
Stamps → view_stamp.xml, colour set from GradePoint.bandFor — tickets 05/07
Dropdowns → TextInputLayout + ExposedDropdownMenu (already in Material 1.12.0)
Bottom nav → view_bottom_nav.xml + BottomNavigationView on 4 top-level screens — new ticket 02b
Entrance motion → UiMotion.fadeUp / .pop (ViewPropertyAnimator, ~30 lines) — ticket 03

Approve the direction and the build order is issues/01 → 08 in .scratch/ui-overhaul/. Nothing functional changes: FR01–FR14, ADR-0003, toasts and the portal API stay exactly as they are.
